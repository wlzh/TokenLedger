# 安全威胁模型

状态：未来实现要求，不是安全审计通过声明。

## 信任边界

供应商/本地日志 -> 上游 CLI -> Collector 内存投影 -> 本地加密队列 -> HTTPS 接入 -> 组织数据库 -> 授权查询/导出。每一跳均验证类型、长度、身份和范围。上游输出、本地文件、员工输入、模型名都不可信。

公司服务器运营者有基础设施访问能力；应用RBAC不能阻止其直接读取数据库。员工自控设备上的统计可被修改，设备认证只证明凭据持有者，不证明真实消费。系统不作为防欺诈或劳动绩效的唯一依据。

## 权限矩阵

| 操作 | Owner | Admin | Member | 设备凭据 |
|---|---|---|---|---|
| 看组织报告 | 是 | 是 | 否 | 否 |
| 看本人报告 | 是 | 是 | 是 | 仅最小设备状态 |
| 邀请普通成员 | 是 | 是 | 否 | 否 |
| 授予管理员/转移Owner | 是，二次验证 | 否 | 否 | 否 |
| 增加个人采集范围 | 只能本人确认 | 只能本人确认 | 本人确认 | 否 |
| 撤销本人设备/授权 | 是 | 是 | 是 | 只能停止自身 |
| 禁用组织内设备 | 是 | 是 | 仅本人 | 否 |
| 修改组织保留政策 | 是，通知成员 | 否 | 否 | 否 |

所有资源按服务端认证身份约束org/member，不信任请求体传来的employee_id。单组织部署仍做组织隔离测试，为未来演进守住边界。最后一个Owner不可被删除；转移需明确接受。

## 威胁与控制

| 威胁 | 必须控制 | 残余风险 |
|---|---|---|
| 设备凭据泄露 | 系统凭据库存储、服务端摘要、轮换/撤销、写入最小权限 | 被控设备可伪造其授权统计 |
| 邀请/配对抢占 | 短期一次性、目标身份验证、限速、配对秘密 | 被盗员工登录会话仍有风险 |
| 越权读取和导出 | 对象级鉴权、角色测试、短期受限下载、审计 | 管理员合法看到已授权组织数据 |
| CLI输出内容泄露 | DTO白名单、拒绝未知字段、无raw日志、预览同源 | 上游变化必须持续回归 |
| 恶意别名/CSV注入 | HTML转义、长度限制、CSV公式安全编码 | 外部表格软件行为需测试 |
| SSRF/凭据跨域 | 不接受任意服务端抓取URL、固定出站目的地、拒绝跨域认证重定向 | 公司代理仍在网络信任链 |
| 本地网页攻击 | 回环绑定、Host/Origin验证、随机会话、CSRF | 同用户恶意进程不在强隔离保证内 |
| 资源耗尽 | 请求大小/速率/并发限制、查询范围、导出配额、子进程超时 | 单机容量有限 |
| 上游/更新供应链攻击 | 版本与来源检查、签名更新、SBOM、依赖扫描 | 上游维护风险仍存在 |
| 重放/乱序/修订污染 | 事务、幂等摘要、修订冲突、授权提交时复查 | 源数据本身可能不真实 |
| 备份恢复已删数据 | 删除墓碑、恢复后重放删除、备份限期销毁 | 无法立刻擦除不可变离线备份 |

## 认证与审计要求

首版管理端应支持并要求管理员MFA；具体认证实现需技术评审，不自创密码学。登录限速、会话吊销、恢复码保护和所有权恢复流程均为上线门。若暂未达到，不得直接发布公网试点。

审计保存谁在何时修改角色、授权、购买、保留策略和导出，不保存业务原始请求、设备秘密或供应商数据内容。基础设施访问日志须屏蔽认证头、Cookie和敏感查询参数。错误追踪默认关闭外部上报，启用需独立告知。

## 安全验收

覆盖匿名访问、成员横向越权、管理员提权、撤销竞态、畸形JSON、超大批次、错误页面泄露、XSS/CSRF、备份恢复、日志秘密扫描。敏感测试只用合成数据；真实安全联系方式和事件处理负责人必须在试点前落实，见 [SECURITY](../SECURITY.md)。
