## 阅读约定

- “源码观察”：在指定提交静态阅读获得，不等于已运行验证。
- “设计要求”：未来实现必须满足，当前未实现。
- “建议默认”：开发前可审议调整，必须版本化记录。
- “未知/不支持”：不得显示成零，不因图表美观而填补数据。
- “完整”：仅对已声明的数据源、设备和时间范围成立，不自动表示完整账号覆盖。
- “首版”：指候选 `v0.1.0`，不是本目录已有运行程序。

先由产品负责人确认 PRD 与边界，再确认数据口径/技术设计，最后授权进入数据样本验证和实现。此目录只含文档，不包含 SQL 迁移；逻辑实体由数据模型描述，实施阶段才生成 DDL/DML 并审核。
