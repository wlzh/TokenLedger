# 员工告知与选择模板

必须由部署公司补充并审核。以下方括号均为待填项，不可原样用于上线。

## 上线前填写

- 运营主体：[公司全称]；目的地：[HTTPS域名]；负责人及隐私联系：[真实渠道]。
- 目的：[预算/续费/报销支持等实际用途]；禁止用途：[绩效评分、劳动工时推断等]。
- 可访问者：[具体角色/团队]；保存期限：[按类别]；托管及备份地区：[地点]。
- 处理依据与选择后果：[经审核的说明]；拒绝/暂停是否影响报销：[明确政策]。
- 访问、更正、删除、申诉流程：[渠道与响应时间]；离职处理：[流程]。

雇佣关系中不能仅凭一个勾选框就假定法律意义上的自愿同意成立。产品提供可选择、可暂停能力；公司仍须审查处理依据、必要性及员工权益，不得把安装默认为全部授权。

## 首次确认示例文案

“你正在连接到[公司]的[域名]。公司将看到你主动选择范围内的产品、额度、统计用量和申报费用，不会收到模型密码、聊天内容或代码。统计可能只覆盖本机，估算费用不等于实际账单。请先查看发送预览，再选择账号与字段。”

选择项默认关闭：账号A额度、账号A可证明归属的用量、指定混合日志范围汇总。混合日志用独立醒目确认，不使用含糊的“提升体验”。活动时间能力首版不提供，不预先勾选未来授权。

## 暂停与撤销示例

“暂停后将停止新的读取和上传。已提交的记录按公司政策保留；正在传输的请求可能已被接收。恢复时不会默认补传暂停期间的消费。你可另外申请删除已有记录。”

服务器显示“员工已暂停上报/数据范围不完整”，不得显示“员工未工作”。主管能了解数据健康，但不能通过提醒轰炸强制隐性授权。

## 员工核对清单

确认域名；确认自己的组织身份；检查每个账号别名及范围；查看真实DTO预览；核对保存期限；知道暂停和申诉入口；知道费用是申报还是来源实测。确认记录保存政策版本和选择范围，不保存无关个人证明材料。
