# v0.1.0 界面与交互设计

状态：线框与交互草案，无网页实现、无可点击原型。本文只描述视觉、内容、交互和状态，不指定前端框架。

## 1. 设计方向

采用浅色“费用账册 + 数据健康台”的工作界面，不使用深色侧栏、不做炫技大屏。首要信息顺序：公司实际支出 -> 员工与产品 -> 使用证据 -> 数据缺失。估算费用永不占据唯一最大的金额卡片。

遵循现有 UI 规范的浅色语义背景、导航、表格与表单规则。页面背景为浅灰，卡片/导航/顶栏白色，表头弱填充。数字右对齐，费用带币种，日期带时区说明。默认表格46px行高，密集模式38px，触屏主要操作目标不少于44px；32px表单控件在移动端使用外围触达区域。

字体选用清晰中文正文与等宽数字组合，具体字体资产与授权在实现前确认。图标用真实 SVG，不用 emoji 或符号冒充状态图标。信息状态必须同时有文字，不能只靠颜色。轻动效仅用于抽屉与加载过渡，尊重减少动态效果设置。

## 2. 信息架构

管理员导航：总览 / 员工 / 产品与订阅 / 购买记录 / 数据健康 / 组织设置。后续才出现费用审批、提醒与财务角色。

员工导航：我的概览 / 我的账号 / 我的订阅 / 我的设备 / 上报与隐私。员工不出现全员排行或公司总花费入口。

所有页面固定显示当前组织；筛选栏标注周期与组织时区。账户别名可见，供应商完整邮箱默认不需要展示。

总览不显示“所有员工真实总工时”。有重叠来源未处理时，token 卡写“可合并来源小计”，同时展示未纳入来源数。

## 5. 员工详情

顶部：员工名、成员状态、所选周期、数据截至时间。概览卡：公司承担费用、登记产品数、可统计用量、覆盖提示。

账号列表列：产品、账号别名、套餐（观测/申报标签）、费用周期、当前额度、token覆盖、最新来源时间。

每个账号详情分四块：购买记录、额度趋势、token及模型分布、来源证据。无法归属日志单独区块，不放入某一账号图表。员工手工认领会显示“员工确认”，不可显示“供应商验证”。

多设备同账号额度冲突时显示选用值及“其他设备有较旧/冲突观察”；不画合并百分比。

“API标价估算”可展开查看价格版本、未定价模型和范围。默认与实付金额隔开显示，不用绿色“节省金额”卡诱导理解。

## 6. 购买登记表单

字段：员工、产品、账号（可选）、套餐、计费模式、开始/结束日期、金额、币种、付款主体、公司承担金额、支付日期、续费日期、备注（长度受限，明确禁止填写密码）。

必填标签与错误提示位于字段旁；金额与币种相邻；年付展示服务期，不擅自除12当现金流。首版不展示文件上传控件。

提交按钮文案“登记购买”，不可写“报销已通过”。记录后可编辑未核验字段并留审计；退款使用“登记退款”并关联原购买，不删除历史付款。

## 7. 员工配对与授权

步骤一：展示公司组织名和完整HTTPS域名，提示“统计发送给这家公司，不发送给上游项目”。

步骤二：选择设备名称，默认通用别名如“工作Mac”，不默认上传系统用户名或真实主机名。

步骤三：本机发现已配置产品；所有账号默认未选。逐项显示可获得指标、读取范围和限制。账号成本无法隔离时显示阻断说明，另提供明确的日志范围授权选项，不偷偷替代账号级授权。

步骤四：预览准确的脱敏上报内容与示例报告。标注首次上报起点，历史回填默认关闭。

步骤五：确认授权，显示完成状态和撤销入口。关闭向导或点击取消不能创建有效授权。

新增账号不会自动加入已授权列表。修改组织域名必须重新配对；不能在普通编辑表单里静默改变上传地址。

## 8. 暂停、解绑与删除交互

暂停立即停止新采集和新上传；本地显示队列保留数量与到期时间，不显示敏感内容。恢复时默认从当前时刻继续，暂停期间不自动回填。

解除某账号授权时提示该账号待传数据将清除，服务器已存在历史按公司政策保留；提供独立“申请删除历史”入口。

撤销设备使用明确确认框：“此设备将不能继续上传，重新使用需要重新配对”。如果在途请求已提交，提示可能已被接收，不承诺已经发送的数据可本地撤回。

删除申请页面显示范围、可能适用的保留说明、预计处理流程和联系人；不能只给一个误导性的“清空所有记录”按钮。

## 9. 状态文案

| 状态 | 主文案 | 不应出现 |
|---|---|---|
| complete_in_scope | 已选来源范围内完整 | 全账号100%完整 |
| partial | 仅包含部分已采集记录 | 已全部统计 |
| unavailable | 暂无可用数据 | 0 token |
| unsupported | 当前版本不支持此指标 | 0元/0小时 |
| auth_required | 请在原应用检查登录 | 请上传你的Cookie |
| stale | 数据已过期，最后更新... | 在线实时 |
| paused | 员工已暂停上报 | 员工未工作 |
| unassigned | 历史账号归属待确认 | 当前账号消费 |
| estimated | 估算，查看计算方法 | 实际账单 |
| manual | 员工/管理员登记 | 官方已核验 |

## 10. 图表与导出

图表使用同一指标/单位，禁止现金和credits混在同一纵轴。不可统计区间留空/标断档而不是补0；鼠标悬停与键盘焦点均能读取来源、日期和单位。模型标签过长可截断但有可访问完整名称。

导出确认显示日期、币种、包含成员、字段、隐私范围与生成截止时间。CSV必须对公式开头字段安全转义。下载受权限与有效期约束，不能使用永久公开URL。

## 11. 响应式与可访问性

桌面以表格和对照阅读为主；平板收起导航；手机优先摘要、员工卡和只读趋势，复杂表格提供字段选择/横向滚动且不隐藏金额单位。保留键盘焦点、可见标签、错误摘要和屏幕阅读器语义。

加载骨架不使用假金额；无数据、过滤后为空、网络失败、权限不足分别显示。页面刷新不丢筛选状态。费用修改有未保存提醒，失败后保留用户输入。

## 12. 设计验收

需审核桌面1440宽、笔记本1280宽与手机390宽场景；测试键盘完成邀请、授权和撤销；确认低对比度辅助文字不承载唯一关键状态。当前线框不是实机截图，后续设计实现需另附真实浏览器证据。
