# TokenLedger

[English](README.md) | [完整文档导航](docs/README.md)

面向小公司的员工自助 AI 订阅、用量与费用管理平台。

**当前仅交付完整设计文档。没有实现客户端、服务端、网页、安装器，也没有部署公网服务。** 项目名已确定为 TokenLedger，公开重名及商标可用性尚未核查。

项目负责人及维护者：[@wlzh](https://github.com/wlzh)。公开文档仓库：[wlzh/TokenLedger](https://github.com/wlzh/TokenLedger)。开源文档不代表已发布可运行软件。

## 解决什么问题

员工可以自行购买不同 AI 产品、使用不同账号；公司希望知道每位员工买了什么、公司承担多少费用、已授权数据范围内用了多少、哪些订阅值得续费以及哪些数据仍不可见。

推荐方案是保留原客户端，通过独立轻量采集端适配 Mac 的 CodexBar 与 Windows 的 Win-CodexBar，只向公司指定的 HTTPS 后台上报白名单统计字段。管理员从公网登录访问，员工也能查看自己的数据。

## 四类信息分别管理

| 类别 | 记录内容 | 不等同于 |
|---|---|---|
| 购买与报销 | 套餐、金额、币种、账期、付款主体 | 实际 token 消费 |
| token 用量 | 可获得的输入、输出、缓存及模型统计 | 完整账号的全部消费 |
| 额度快照 | 各时间窗口的剩余/已用比例、重置时间 | 可反推的 token 数 |
| 使用活动 | 最近活动、使用天数；后期增加可解释的时长估算 | 工时、考勤、生产力 |

费用进一步区分：实付金额、服务商计量金额、API 标价估算。充值与余额消耗不重复计入费用。

## 第一版边界

- 单组织自托管，用户逐个邀请，管理员和员工数据权限隔离。
- 员工显式选择账号、查看上报预览、暂停和解除绑定。
- 支持范围由真实样本验证决定；优先 Codex、Claude，Cursor 两端分别验证。
- 先完成额度快照、可靠的日级 token 汇总和订阅登记。
- 模型级细分只在来源提供时展示；账号归属不明时保留待认领记录。
- 不采集聊天内容、源代码、项目路径、浏览器历史、键盘或屏幕。
- 不自动切换账号、不兑付额度、不购买套餐、不执行远程命令。
- 不把现有 CodexBar 本地服务直接暴露至公网。
